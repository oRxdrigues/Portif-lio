# Aplicativo de Portfólio Jean Rodrigues

Aplicação premium de currículo interativo e portfólio pessoal criada com React, Vite, Tailwind CSS e Framer Motion.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
```

## Deploy na Vercel

```bash
npm install
npm run build
npm run deploy:preview
```

Para publicar direto em produção:

```bash
npm run deploy
```

## Destaques

- Fluxo de portfólio pensado primeiro para celular com navegação inferior
- Seções de Boas-vindas, Sobre, Habilidades, Formação, Projetos, Experiência, Conquistas, Contato e Perfil/Configurações
- Identidade em gradiente azul, superfícies em glassmorphism, espaçamento responsivo e animações sutis
- Alternância de tema escuro
- Download de currículo funcional em `public/resume-jean-rodrigues.pdf`
